# Overview

The **Terminal-Based Work Management System** is designed to help users create, view, and manage work tasks efficiently. This project allowed me to deepen my understanding of object-oriented programming, file handling, and terminal-based interfaces in TypeScript. By building this software, I aimed to improve my skills in designing robust, user-friendly applications while learning best practices for code organization and error handling.

The purpose of this software is to provide a simple, terminal-based solution for managing tasks. Users can add tasks, mark them as complete, view a list of all tasks, and store tasks persistently in a file. This project demonstrates practical use of classes, abstract classes, interfaces, asynchronous functions, lists, and exception handling in a real-world-like application.

# Development Environment

The development environment for this project included:

- **Visual Studio Code**: Used as the main IDE for writing and testing TypeScript code.  
- **Node.js**: Provides the runtime environment to execute JavaScript generated from TypeScript.  
- **TypeScript**: The programming language used to implement the software, allowing for type safety, classes, interfaces, and modern JavaScript features.  
- **Terminal/Command Prompt**: Used to interact with the software and execute compiled JavaScript files.
